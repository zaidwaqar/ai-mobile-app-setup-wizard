# Contributing

Thanks for helping improve this project.

## Quick start

```bash
npm install
npm test
npm run lint
npm run typecheck
```

## Development

```bash
npm run start
```

Scan the QR code with Expo Go (iOS or Android).

## What to work on

- Improve the wizard questions without making them technical.
- Improve architecture decision logic (local-only vs cloud-backend) with clear reasoning.
- Improve mobile UI polish and accessibility.
- Add more test cases for edge scenarios.

## Pull requests

- Keep PRs small and focused.
- Update or add tests for behavior changes.
- Do not add or request real secrets in issues or PRs.
- Run `npm test`, `npm run lint`, and `npm run typecheck` before opening the PR.

## Commit style

Use clear messages like:

- `wizard: improve /continue resume logic`
- `ui: polish composer layout`
- `docs: clarify local-only vs backend guidance`
